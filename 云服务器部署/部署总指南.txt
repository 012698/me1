=== 云服务器部署总指南 ===
=== LENG_MING 小游戏社交网站 全栈部署 ===

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、购买云服务器（免备案推荐）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方案A【推荐·免费】：阿里云高校计划
  地址：https://university.aliyun.com
  需学生认证，免费领 ECS（2核2G）
  地域选：香港（免备案）

方案B【推荐·便宜】：腾讯云校园计划
  地址：https://cloud.tencent.com/act/campus
  轻量应用服务器 2核2G，约 9 元/月
  地域选：香港（免备案）

方案C：Cloudflare Tunnel（免费，不需公网IP）
  适合：校园网/家宽等无公网IP环境
  下载：https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
  用法：
    chmod +x cloudflared-linux-amd64
    ./cloudflared-linux-amd64 tunnel --url http://localhost:3000
  会自动分配一个 xxx.trycloudflare.com 地址
  ⚠️ 地址每次重启会变，不适合正式部署

系统选择：Ubuntu 22.04 LTS 或 Debian 12

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
二、上传后端文件到服务器
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法A：scp 命令
  scp -r 后端/* root@你的服务器IP:/opt/lengming/

方法B：SFTP 工具（WinSCP / FileZilla）
  把"后端"文件夹整个拖到 /opt/lengming/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、一键部署后端
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SSH 登录服务器后：
  cd /opt/lengming
  chmod +x deploy.sh
  bash deploy.sh

脚本自动完成：
  ✅ 安装 Node.js 22+
  ✅ npm install 安装依赖
  ✅ 创建 .env 配置文件（自动生成 JWT 密钥）
  ✅ PM2 启动 + 开机自启

完成后输出：http://服务器内网IP:3000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
四、开放防火墙端口
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

服务器防火墙：
  sudo ufw allow 3000/tcp     (Ubuntu)
  sudo firewall-cmd --permanent --add-port=3000/tcp && sudo firewall-cmd --reload  (CentOS)

云平台安全组（必须！）：
  腾讯云：控制台 → 轻量服务器 → 防火墙 → 添加规则 → 端口3000/TCP
  阿里云：控制台 → ECS → 安全组 → 入方向 → 添加 → 端口3000/TCP → 0.0.0.0/0

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
五、前端配置（改一行代码）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

打开 index.html，找到第16行附近，改两行：

  改前：
  const API_BASE = 'https://你的render应用名.onrender.com';
  const WS_BASE = 'wss://你的render应用名.onrender.com';

  改后（假设服务器IP是 123.45.67.89）：
  const API_BASE = 'http://123.45.67.89:3000';
  const WS_BASE = 'ws://123.45.67.89:3000';

然后重新部署前端到扣子 Pages。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
六、验证部署
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 浏览器打开 http://你的服务器IP:3000/api/health
   应返回 {"status":"ok"}

2. 打开前端网站，测试登录、聊天、好友功能
   游戏功能是离线的，不需要后端

3. 查看后端日志：pm2 logs lengming-api

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
七、日常运维
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  pm2 status              # 查看服务状态
  pm2 logs lengming-api   # 实时日志
  pm2 restart lengming-api  # 重启
  pm2 stop lengming-api   # 停止

  数据库备份：cp data/app.db data/app.db.backup
  管理员密码：编辑 .env 中的 ADMIN_PASSWORD，然后 pm2 restart lengming-api
  deploy.sh 会自动随机生成 JWT_SECRET 并写入 .env

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
八、可选：绑定域名 + HTTPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  sudo apt install nginx certbot python3-certbot-nginx -y
  Nginx 配置反向代理 3000 端口
  certbot --nginx -d your-domain.com  申请免费 HTTPS 证书
  配了 HTTPS 后，前端 API_BASE 改为 https://your-domain.com
  WS_BASE 改为 wss://your-domain.com
