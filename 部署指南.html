第1步 · 注册 Northflank

  1. 打开 https://app.northflank.com/signup
  2. 用 GitHub 账号登录（推荐）或 Google/邮箱注册
  3. 注册后自动进入 Dashboard，选择 Sandbox 计划（免费，无需信用卡）
Sandbox 免费额度：2个常驻服务 + 1个免费数据库 + 2个定时任务。服务不休眠，WebSocket 不会断。256MB 内存够跑你的后端。

第2步 · 上传代码到 GitHub

Northflank 从 GitHub 拉代码来构建部署。你需要先把后端代码推到 GitHub。

2.1 创建 GitHub 仓库

  1. 登录 GitHub → New repository
  2. 仓库名：lengming-backend
  3. 选 Private（推荐，因为含数据库连接串）
  4. 不要勾选 README / .gitignore / License
  5. 点 Create repository

2.2 推送代码

在你本地电脑的终端执行：

cd backend_pg   # 进入后端代码目录

# 初始化 Git
git init
git add .
git commit -m "init: LENG_MING backend (PostgreSQL)"

# 推送到 GitHub（把 YOUR_USERNAME 换成你的 GitHub 用户名）
git remote add origin https://github.com/YOUR_USERNAME/lengming-backend.git
git branch -M main
git push -u origin main
重要：推送前确认 .env 文件不在代码目录里（只有 .env.example），避免泄露数据库密码。当前代码已经脱敏，.env.example 里都是占位符，安全。

2.3 需要推送的文件清单

server.js · package.json · .env.example · deploy.sh · README_部署.md

你拿到的部署整理包里 后端/ 目录就是这些文件，解压后直接用。

第3步 · 在 Northflank 创建服务

  1. 回到 Northflank Dashboard
  2. 点 Create project，名称填 lengming
  3. 在项目里点 Create service
  4. 选择 From Git repository
  5. 连接你的 GitHub 账号，选择 lengming-backend 仓库
  6. 分支选 main
  7. Build type 选 Buildpack（自动识别 Node.js，零配置）
  8. Compute plan 选 nf-compute-10（0.1 vCPU / 256MB，免费额度内）
  9. 点 Deploy
Buildpack 自动处理：读 package.json → 运行 npm install → 用 npm start 启动。package.json 里已经写好了 "start": "node server.js"，不用改任何东西。

第4步 · 配置环境变量

部署会先失败（因为缺少 DATABASE_URL），这是正常的。现在来设置环境变量：

  1. 在 Service 页面点 Secrets（或 Environment variables）
  2. 逐条添加以下变量：
变量名值说明
DATABASE_URL postgres://avnadmin:AVNS_ZqyqrkG7U9AK6SUFmKv@lengming-project-b92b.h.aivencloud.com:23420/defaultdb?sslmode=require 你的 Aiven 连接串
PG_SSL true Aiven 需要 SSL
JWT_SECRET 点下方按钮生成 JWT 签名密钥
ADMIN_PASSWORD 你自己定一个 管理后台密码，自己记住

生成 JWT_SECRET

在终端运行：

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

把输出的64位十六进制字符串填到 JWT_SECRET 里。

ADMIN_PASSWORD：这是你管理后台的登录密码，自己定一个（比如 LengMing2026!），一定要记住。部署后别人无法查看这个值。
  1. 设置完后，点 Redeploy 重新部署
  2. 等构建完成，状态变为 Running

第5步 · 获取后端地址

部署成功后，在 Service 页面找到 External endpoints 区域，会看到类似这样的地址：

https://lengming-backend-xxxx.northflank.app

这就是你的后端 API 地址。WebSocket 地址把 https:// 改成 wss://：

wss://lengming-backend-xxxx.northflank.app
验证：在浏览器打开 https://你的地址/api/health，看到 {"status":"ok","db":"connected"} 就说明后端+数据库都通了。

第6步 · 更新前端 API 地址

拿到后端地址后，告诉我，我会帮你：

  1. 修改 index.html 第16-17行的 API_BASE 和 WS_BASE
  2. 重新部署前端到扣子 Pages
  3. 验证全栈功能

如果你想自己改，只需要改两行：

// 第16行：把占位符换成你的 Northflank 地址
const API_BASE = 'https://lengming-backend-xxxx.northflank.app';
const WS_BASE = 'wss://lengming-backend-xxxx.northflank.app';
